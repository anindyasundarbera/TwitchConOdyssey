# Narrow agent task packet — reusable dispatch template

This is a research/documentation template, not agent configuration or standing authorization.

## Fill before delegation

- Task ID and date:
- Outcome and precise question:
- Authorization: research / discovery / implementation / verification; link the user's current gate.
- Read first: PROJECT-CONTEXT.md, then only the relevant topic note and applicable AGENTS.md.
- Current facts: claim IDs, supporting source/evidence paths, freshness date.
- Constraints and unknowns relevant to this task:
- Ownership: exact files permitted to change; all other files read-only. Other agents share the workspace; preserve their edits.
- Prohibitions: explicitly name disallowed runtime, network, credential, publication, or implementation operations.
- Acceptance criteria and evidence required:
- Model and effort: narrow extraction starts with the available lower-cost worker; ambiguous reconciliation or technical synthesis uses a workhorse; escalate only for an identified problem.
- Scope budget: bounded sources/tool calls, concise output, no further delegation unless specifically authorized.

## Return contract

Write details to the assigned topic note; return at most 250 words to the coordinator:

1. Outcome and file path.
2. Up to five decisive findings, with claim IDs or exact sources.
3. Conflicts, inaccessible sources, and unverified behavior.
4. Next dependency or decision; do not begin it.

Keep a short source ledger with URL, retrieval date, supported claim, confidence, and any temporal conflict. Preserve enough evidence to revisit a conclusion without reproducing entire documents. Task notes are navigation aids; live behavior needs actual traces/tests.

## Context discipline

Start independent research with fresh context and an explicit packet. Load topic notes only when needed. Resume an existing specialist for closely related follow-ups when its retained context is useful; use a fresh packet for a new topic. Never assume a new session remembers this conversation or automatically discovers these files. Supply the index path explicitly until a separately approved instruction/configuration change makes discovery automatic.
